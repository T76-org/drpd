# Installing Dr. PD as an app

Dr. PD runs in Chrome or Edge, but supported browsers can also install the
control software as a standalone app. This gives Dr. PD its own app window and
launcher entry while keeping the same browser-based USB access model.

## Install from the Help menu

After opening the control software in Chrome or Edge, choose **Help -> Install
Dr. PD as app...** and follow the browser prompt.

This does not install a driver or change how Dr. PD communicates with your
computer. Pairing, USB permissions, and device access still work through the
browser. The installed app is simply another way to launch the same control
software.

## When the menu item appears

The install menu item is shown only when the browser reports that Dr. PD can be
installed. It may be hidden when:

- The app is already installed.
- Dr. PD is already running in standalone app mode.
- The current browser, URL, or browser state does not offer web-app
  installation.

If the menu item is not visible, you can still use Dr. PD normally from Chrome
or Edge.

## After installation

Launch Dr. PD from the app entry created by your operating system or browser.
If your device is already paired, the app can reconnect to it from the Device
menu. If it is not paired yet, choose **Device -> Pair new device...** and
approve the browser USB permission prompt.
