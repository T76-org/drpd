# Analog Monitor

The Analog Monitor section of Dr. PD is responsible for monitoring all voltages and currents in the system, including the VBUS lines of both USB-C ports, the 5V and 3.3V rails, various internal voltages, and system ground.

## VBUS current monitoring

The shunt resistor R202 sits in series with the VBUS line at Port 1, producing a 5mV/A voltage drop proportional to the current flowing through it.

U201, an INA240-A2 current-sense op-amp, amplifies this voltage drop by a factor of 50V/V. At the device maximum of 6A, the 30mV voltage drop across R202 therefore corresponds to a 1.5V output from U201. This is sufficient to cover the 0-5A range of the USB-PD specification, with some headroom to make characterizing the response of DUTs to overcurrent events.

Since the current can flow in both directions, the U201 is biased with a 1.65V reference voltage generated by U304, a TLV431 adjustable shunt regulator. This allows the output of U201 to swing above and below the 1.65V reference voltage, producing a 0-3.3V output that is proportional to the current flowing through R202—perfect for the ADC of the microcontroller to read and process.

We chose R202 to minimize the burden voltage on the VBUS line while still producing a reasonable voltage drop for U201 to amplify. To minimize noise and maximize the accuracy of the circuit, we use Kelvin connections of exactly the same length between the shunt resistor and the op-amp.

Despite this, there are still enough factors at play that reduce the absolute accuracy of the current measurement, including op-amp offset voltages, resistor and shunt reference tolerances, and PCB trace resistance. 

To account for this, we calibrate the firmware at the factory using a multi-point linear regression to map the raw ADC readings to actual current values. The firmware stores its calibration coefficients in the device's non-volatile memory and uses them to correct the readings during normal operation. To account for drift in the accuracy of the 1.65V reference over time, the firmware also periodically samples it and uses the measured value as the zero point for the current measurement.

## VBUS voltage monitoring

Resistors R301 and R302 form a voltage divider that scales VBUS by a theoretical factor of 1/18.405, producing a 0-3.26V swing for the 0-60V range that Dr. PD supports. Since USB-PD maxes out at 48V when in EPR mode, this is more than sufficient to cover the entire range of voltages that can be applied to the VBUS line. The resulting sense voltage is buffered by U301A, and fed to the ADC of the microcontroller for processing.

Naturally, the voltage divider is not perfect, and the actual scaling factor will be different based on tolerances, voltage offsets, ON time, temperature, and so on. To account for this, the firmware also calibrates the VBUS voltage measurement at the factory using a multi-point linear regression to map the raw ADC readings to actual voltage values, much like with the current measurement.

## Voltage monitoring multiplexer

Since they are critical measurements for which the highest accuracy is required, current and voltage sensing on VBUS both have separate circuitry that feeds directly into a dedicated ADC channel of the microcontroller.

Several other voltages in the system are not as critical, and so they are multiplexed using U302, a 74HC4051D analog switch. The microcontroller can select one of the input channels using the `CC_VSENSE_x` signals, and the output of the multiplexer is buffered through U301B, and then divided by a factor of 1/1.51 using R303 and R304. This is required because older USB-PD devices can operate at 5V on the CC lines.

In addition to the individual CC lines on both ports, the multiplexer also monitors system ground, the 1.65V reference voltage, and the 3.3V reference voltage fed to the ADC.
