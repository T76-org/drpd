# BMC decoder configuration

Dr. PD exposes advanced physical-layer controls through **Device → Calibrate → Internal settings…**.
These controls tune the CC comparator reference generated by PWM. Incorrect values can stop
Dr. PD from decoding USB Power Delivery traffic, so the app displays a safety warning before
opening the settings. Selecting **Do not show this again** suppresses that warning only in the
current browser profile.

| Setting | Default | Allowed values | Unit |
| --- | ---: | --- | --- |
| CC reference voltage | 0.70 | 0.20–2.50 in 0.05 increments | V |
| VREF PWM frequency | 100000 | 10000–500000 in 1000 increments | Hz |

Edits remain local until **OK** is selected. Accepted changes apply immediately and persist in
device flash, so they remain active after restart. Each **Reset** button stages the
firmware build-time default; select **OK** to save it.

If communication becomes unreliable, reconnect Dr. PD and restore both defaults through the same
dialog or use the corresponding SCPI `:RESet` commands. Firmware rejects values outside the listed
ranges and increments.

Python callers can use `device.system.configuration.bmc_decoder`; TypeScript callers can use
`device.system.configuration.bmcDecoder`. See generated API and SCPI references for exact methods
and commands.
