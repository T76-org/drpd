# Installing from PyPI

The Python package name is `t76`. It requires Python 3.11 or newer.

:::warning[PyPI publication in progress]
The `t76` package is not published on PyPI yet. For now, install it from a
local clone of the repository using the editable-install instructions below.
:::

## Install from PyPI

Once publication is complete, install with:

```bash
python -m pip install t76
```

For a clean project environment:

```bash
python -m venv .venv
source .venv/bin/activate
python -m pip install --upgrade pip
python -m pip install t76
```

## Install from the repository

You can also clone the repository and install the package directly from its
`python` directory. This is the current installation method while PyPI
publication is in progress:

```bash
python -m venv .venv
source .venv/bin/activate
python -m pip install --upgrade pip
python -m pip install -e ./python
```

For development tools:

```bash
python -m pip install -e "./python[dev]"
```

## Run the terminal app

After installation, run the Dr. PD terminal app:

```bash
drpd
```

The module entry point remains available:

```bash
python -m t76.drpd
```

You can also list available top-level apps:

```bash
python -m t76 --apps
```

## Platform notes

The library talks to Dr. PD over USBTMC through PyUSB. Your operating system must allow the Python process to access the Dr. PD USB interface.

On Linux this may require a udev rule. On macOS and Windows, make sure no other app has exclusive access to the device while the script is running.
