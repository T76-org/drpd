# Simple Python demo

This script discovers Dr. PD devices, connects to the first device, reads basic status, checks capture state, and disconnects cleanly.

It does not request a sink power contract or change VBUS behavior.

```python
import asyncio

from t76.drpd.device import find_drpd_devices


async def main() -> None:
    devices = find_drpd_devices()
    if not devices:
        print("No Dr. PD devices found.")
        return

    device = devices[0]
    await device.connect()

    try:
        info = await device.system.identify()
        mode = await device.mode.get()
        mode_status = await device.mode.get_status()
        capture_status = await device.capture.get_status()
        analog = await device.analog_monitor.get_status()

        device_label = device.name or f"{info.model} {info.serial_number}"
        print(f"Connected to {device_label}")
        print(f"Model: {info.model}")
        print(f"Serial number: {info.serial_number}")
        print(f"Firmware version: {info.firmware_version}")
        print(f"Hardware revision: {info.hardware_revision or 'unknown'}")
        print(f"Mode: {mode.value}")
        print(f"Mode status: {mode_status.value}")
        print(f"Capture: {capture_status.value}")
        print(f"VBUS: {analog.vbus:.3f} V, {analog.ibus:.3f} A")
    finally:
        await device.disconnect()


if __name__ == "__main__":
    asyncio.run(main())
```

## Running the script

Save the file as `drpd_demo.py`, then run:

```bash
python drpd_demo.py
```

If the browser control app is connected to Dr. PD, choose
**Device → [device name] → Disconnect** and wait for it to release the USB
interface before running the script. Closing the app or browser tab is a
fallback. Only one application can claim the device interface at a time.
