# Pairing Dr. PD with your computer or tablet

In order to use Dr. PD, you need to pair it with the control software. This is a one-time process that establishes a secure connection between the device and your browser; after pairing, the device will automatically reconnect to the control software whenever it is plugged in.

You can pair your device by choosing **Device → Pair new device...** in the control software. Chrome will then show a list of available USB devices. Select the entry for Dr. PD, and click Connect.

If you prefer to launch Dr. PD like a desktop app, see
[Installing Dr. PD as an app](../how-to/installing-as-app.mdx). Pairing still
works the same way after installation; the app install only changes how the
control software is launched.

**That's it!** Dr. PD is now connected and ready to use. You can proceed to the next step of [testing a USB-PD source](./testing-usb-source), or explore the various features and settings in the control software.
