# Get started in 5 minutes (or less)

Connecting Dr. PD to your computer and getting your first USB-PD capture is quick and easy. This guide will walk you through the steps to get up and running in no time.

## Things you will need

1. A computer with a recent version of Chrome or Edge and a USB port. Dr. PD runs on Windows, macOS, Linux, and Android.
2. A USB-C cable to connect Dr. PD to your computer or tablet. This cable must support USB 2.0 communications in order to run the control software, but it does not need to support USB-PD or high-speed data transfer.
3. A USB-PD source to test, such as a charger, power bank, or USB-C port on a laptop.
4. A USB-C cable.
